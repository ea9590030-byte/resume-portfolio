# 個人簡歷網頁設計與 Git/GitHub 實作

## 專案簡介
本專案為個人單頁式簡歷網站，包含個人資訊、技能展示、經歷時間軸與專案作品集四大區塊，並支援響應式設計（RWD）與平滑捲動效果。

## 版本控制操作說明

### git revert 還原紀錄與原因
- 還原內容：撤銷 `chore: temporarily add test label to page title` 加上「(測試版)」標題的修改。
- 還原原因：該字樣僅用於測試版本控制撤銷流程，正式網頁不應保留測試字眼，因此使用 `git revert` 安全還原並保留完整提交歷史。
### A/B 版本測試與選擇說明
- **版本 A（`feature/skills-gradient`，已採用並合併）**：採用藍紫漸層進度條搭配微陰影設計。
  - **採用原因**：進度條能更直觀呈現各項技能的熟練度比例，漸層色彩與陰影也與整體現代卡片風格一致，視覺層次較佳。
- **版本 B（`feature/skills-tags`，未採用並保留 PR）**：改為膠囊狀標籤雲排版。
  - **未採用原因**：雖然標籤雲節省垂直空間，但僅有 3 項技能時版面略顯單薄，且較無法一眼看出各項技能之間的熟練程度差異，因此保留 PR 作為紀錄但不合併。
